Web-based Portfolio แสดงผลงานการวิเคราะห์และออกแบบระบบ **"Event Registration Process Improvement"** (ระบบปรับปรุงกระบวนการลงทะเบียนกิจกรรม)

โปรเจกต์นี้ถูกพัฒนาขึ้นเพื่อนำเสนอ Case Study ในรูปแบบ Interactive Web Application ที่ทันสมัย ใช้งานง่าย และสวยงาม แทนการนำเสนอผ่านเอกสาร PDF หรือ Slide แบบเดิมๆ

## 📋 เกี่ยวกับโปรเจกต์ (About The Project)

เว็บไซต์นี้รวบรวมขั้นตอนการวิเคราะห์ระบบทางธุรกิจ (Business Analysis) ตั้งแต่ต้นจนจบ:
* **Executive Summary:** ภาพรวมโครงการ
* **Problem Analysis:** วิเคราะห์ปัญหาและความเจ็บปวดของผู้ใช้งาน (Pain Points)
* **Root Cause Analysis:** หาสาเหตุที่แท้จริงด้วย 5 Whys & Fishbone Diagram
* **As-Is & To-Be Process:** เปรียบเทียบกระบวนการทำงานเดิมและใหม่
* **Solution & Impact:** โซลูชันที่นำเสนอและการประเมินความคุ้มค่า (ROI)

## ✨ ฟีเจอร์หลัก (Key Features)

* **Modern UI/UX:** ดีไซน์แบบ Glassmorphism และ Sidebar Navigation
* **Interactive Dashboard:** แสดงข้อมูลสรุปและกราฟวิเคราะห์
* **PDF Export:** ฟังก์ชันจัดหน้าอัตโนมัติเพื่อบันทึกเป็นไฟล์ PDF สำหรับแนบสมัครงาน
* **Responsive Design:** รองรับการแสดงผลทั้งบน Desktop และ Mobile

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

โปรเจกต์นี้ถูกออกแบบให้เป็น **Single File Application** เพื่อความสะดวกในการเปิดดูและแก้ไข โดยไม่ต้องติดตั้ง Environment ที่ซับซ้อน

* **HTML5**
* **React.js** (via CDN)
* **Tailwind CSS** (via CDN)
* **Babel** (via CDN for JSX processing)

## 🚀 วิธีการใช้งาน (How to Run)

1.  ดาวน์โหลดหรือ Clone repository นี้
2.  เปิดไฟล์ `index.html` ด้วย Web Browser (Chrome, Edge, Safari) ได้ทันที
3.  ไม่จำเป็นต้องใช้ `npm install` หรือ `node.js`
